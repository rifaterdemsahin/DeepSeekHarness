The model can be anyone's.
The harness should be yours.

A harness is everything around an LLM that turns "text in, text out" into "reads my repo, edits files, runs tests, and proves it". Codewhale is the popular open-source one for DeepSeek models (and 40+ other providers).

⚡ 60-second start

curl -fsSL https://codewhale.net/install.sh | sh   # macOS / Linux, no account
cd your-git-repo
codewhale                                          # then /provider → paste a DeepSeek key
# type:  Fix the failing tests and explain what changed.
⚠️ Commit or stash first. Then /undo is a safety net, not your only one.
