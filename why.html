🧠 Why it makes sense: first principles

Strip away the hype. What is a coding agent, really?

1️⃣ An LLM can only emit text

It cannot read your disk, run pytest, or remember yesterday. Everything beyond "predict the next tokens" has to be supplied from outside.

2️⃣ So an agent = model + loop + tools

flowchart LR A[🧠 Model proposes an action] --> B[🛠️ Harness executes it] B --> C[👀 Result goes back as context] C --> A B -. gate .-> D[🛡️ permission check]

That outer loop is the harness. The model supplies judgment; the harness supplies hands, eyes, memory and brakes.

3️⃣ Therefore the harness decides the outcome

4️⃣ Why separate harness from model?

flowchart TB subgraph Coupled[❌ Coupled: vendor CLI] V1[One model] --- V2[Closed loop] end subgraph Decoupled[✅ Decoupled: Codewhale] D1[Any model] --- D2[Open loop you can read] end Coupled -->|model gets better elsewhere| X[😬 stuck] Decoupled -->|swap one line| Y[😎 upgrade instantly]

Models improve and reprice monthly. Your workflow (rules, hooks, skills, approvals) should not be rebuilt each time. Owning the harness makes the model a replaceable part.

5️⃣ Trade-offs (be honest)

  • ⚠️ Telemetry is on by default (aggregate counts only). Turn off: codewhale config set telemetry false.
  • ⚠️ Full Access disables the sandbox. Windows has no OS sandbox yet.
  • ⚠️ Fast-moving project: modes change in 0.10.3. Read the versioned docs for your install.
  • ⚠️ A cheaper model may need more review than a frontier one. The receipts make that cheap to do.
